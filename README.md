# Probability for Machine Learning

This repository contains my study and practical implementation of probability concepts as part of my Math for Machine Learning roadmap.

The notebook covers fundamental probability concepts, common probability distributions, statistical principles, and Python simulations to explore how probability works in practice.

## Topics Covered

- **Probability Basics:** Sample spaces, events, outcomes, and probability calculations.
- **Probability Rules:** Complement, addition, and multiplication rules.
- **Conditional Probability:** Calculating probabilities using known information.
- **Bayes' Theorem:** Updating probabilities when new evidence becomes available.
- **Random Variables:** Discrete and continuous random variables, PMF, PDF, CDF, expected value, variance, and standard deviation.
- **Probability Distributions:** Bernoulli, Binomial, Uniform, and Normal distributions.
- **Law of Large Numbers (LLN):** Exploring how sample proportions approach theoretical probabilities.
- **Central Limit Theorem (CLT):** Investigating the distribution of sample means.
- **Python Implementation:** Calculations, random simulations, and visualisations.

## Tools and Libraries

- Python

## Getting Started

### 1. Clone the repository

```bash
git clone https://github.com/Tobi454/probability-for-machine-learning.git
```

### 2. Navigate to the project directory

```bash
cd probability-for-machine-learning
```

### 3. Install the required libraries

```bash
python -m pip install numpy scipy matplotlib notebook
```

### 4. Launch Jupyter Notebook

```bash
jupyter notebook
```

Open the notebook file and run the cells in order.

## Practical Work

The notebook includes:

- Calculating theoretical probabilities.
- Implementing Bayes' theorem with a medical testing example.
- Computing expected values and variance.
- Working with probability distributions using SciPy.
- Simulating coin tosses to demonstrate the Law of Large Numbers.
- Exploring the Central Limit Theorem using sample means.
- Visualising Bernoulli, Binomial, Uniform, and Normal distributions.
- Comparing simulated probabilities with theoretical probabilities.
